## Decisions
| Decision | Why |
|---|---|
| Expo React Native + TypeScript | Big ecosystem, fast iteration, APK via EAS; safer offline storage than a PWA |
| Plain expo-sqlite instead of Drizzle | Small schema; avoids extra bundler/migration tooling |
| Apps Script web app for sync | No Google login in the app; a shared secret is enough for a few trusted users |
| Newest change wins (`updatedAt`) | Few users, low conflict risk |
| Pull by server `syncedAt` | Phone clock skew can't make a phone miss rows |
| Delayed payment = `paidAt` null | The period starts on the due date regardless of when money arrives |
| Dark theme, red accent (#E53935) | Matches the Stitch prompt |
| Default amount 3.000 RSD | Placeholder; can be changed in Podešavanja |
| Serbian Latin script | Assumed; confirm |
| GitHub Releases + Obtainium | Updates without the Play Store; GitHub over GitLab because Obtainium supports it best |
| EAS remote versionCode, auto-increment | Each build gets a higher code, so installs update in place (same keystore) |
| Sync schema check (`MIN_SERVER_SCHEMA`) | A new app with an old script stops before clearing dirty rows, so no data is lost |
| Code.gs matches columns by header | Columns can be added without breaking older sheets or hand-added columns |
| Any discipline, not only kickbox | User request 2026-11-13. Texts made neutral; package id `rs.kickbox.clanarina` kept on purpose (changing it = new app, breaks updates; users never see it) |
| Icon: calendar + check | Sport-neutral; generated by `scripts/make_icons.py` (kept in the repo now) |
| Trainer view = generated sheet tab | "Pregled članova" rebuilt by Code.gs, not formulas: same status logic as the app (parity test), colors, plain sentences |
| SheetJS from cdn.sheetjs.com | The npm `xlsx` package is outdated; 0.20.3 is the maintained build |
