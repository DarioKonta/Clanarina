# Kick box članarina

Android app for tracking kickbox club membership payments (Serbian UI). It works offline and syncs with Google Sheets through a Google Apps Script web app.

- **Stack:** Expo + React Native + TypeScript, expo-sqlite (Drizzle), React Native Paper, EAS Build (APK)
- **Docs:** [CLAUDE.md](CLAUDE.md) (architecture, conventions), [SESSION_STATE.md](SESSION_STATE.md) (progress)

## Push to GitLab (first time)
1. Create an empty project on GitLab. Don't add a README, so the first push doesn't conflict.
2. In this folder, run:
   ```bash
   git remote add origin https://gitlab.com/<user>/<project>.git
   git push -u origin main
   ```
